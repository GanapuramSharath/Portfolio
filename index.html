My Projects

Face Emotion Recognition

This project is a real-time facial emotion recognition system built using Python, OpenCV, and a Convolutional Neural Network (CNN). The model is trained on the FER-2013 dataset, a widely used dataset for facial expression analysis, which contains grayscale images of facial expressions categorized into seven emotions: happy, sad, angry, surprise, fear, disgust, and neutral. The system captures live webcam footage, detects faces using Haar cascades, and classifies the detected faces into emotion categories using the trained CNN model.

Tech Stack: Python, TensorFlow, OpenCV

Toxic Comment Classification Using Deep Learning

This project is a deep learning-based NLP application that detects and classifies toxic comments (e.g., insults, threats, hate speech) in text using a hybrid CNN-RNN architecture. The model is trained on the Jigsaw Toxic Comment Classification dataset, which contains thousands of labeled comments from Wikipedia. The pipeline includes data cleaning, tokenization, embedding (like GloVe or word2vec), and model tuning. The final model performs multi-label classification across several toxicity categories.

Tech Stack: Python, TensorFlow
